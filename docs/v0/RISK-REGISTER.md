## Not established by this audit

This is not a complete security audit, full authorization proof, license clearance, performance benchmark, provider compatibility certification, production schema verification, or execution of every route. The raw supplied dump contained credentials and personal/financial data; those rows and the real `baseInfo.php` are excluded from the repository and tests. Validity/rotation of any original credentials is the operator's private task, not a public issue payload.

## Disposition

Carry these identifiers into work for the relevant increment rather than create a duplicate issue for every line. Current V0 must preserve the source and capture the behaviors. A blocker that makes the **new harness** unsafe or falsely green must be fixed before V0 acceptance. An existing product defect is separately scoped; ambiguous intended behavior is retained. New fixes need explicit input/outcome tests and acceptance, and must never be disguised as schema normalization or bulk replacement of legacy names.
